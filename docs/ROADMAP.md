# Development roadmap

Stages 0–4 are implemented and verified. The user's Stage 4 semantic-retrieval specification replaces the previous milestone ordering. Retrieval evaluation labels remain provisional at the user's request; no independently human-reviewed benchmark quality is claimed. Later stages describe possible acceptance targets, not implemented functionality.

| Stage | Scope | Acceptance criteria |
| --- | --- | --- |
